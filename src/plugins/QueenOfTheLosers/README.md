# Queen of the Losers

Allows Configuration of the \"King of the Losers\" screen to show other titles, such as Queen / Ruler.

Syncs choice to other clients who also have the mod so the correct title is shown to everyone.

Use the [REPOConfig](https://thunderstore.io/c/repo/p/nickklmao/REPOConfig/) mod to change the title while in game.

If the host has the mod, titles will be synced with all clients who also have the mod. 
If the host does not have the mod, clients will only see their own title, and will be shown to everyone else as King.

Currently (due to limitations in the config api) I have to define each title that can be used. If you want more to be added, let me know and I can add them in a future update.
The following titles are currently available: Queen, Ruler, King, Monarch.
